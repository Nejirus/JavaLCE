# Legacy Console 1.17.1 — 2.3.7

* Added **Play Tutorial** directly below **Create New World**. Each click opens
  a fresh copy of the original PS4 tutorial; existing saves stay in the list.
* Converted the original saved map and its container rules, including all 12
  tagged music discs, original spawn and starting-area progression restriction.
* Adapted the recovered PS4 tutorial task graph and menu guides to Forge/Java.
* Added PS4 block descriptions, Legacy4J descriptions for newer blocks, and a
  Hints switch for optional prompts. Tutorial instructions stay active.

Use Forge **37.1.1**, Minecraft **1.17.1**, and Java **17**. Supplied OptiFine
**H1** and LCE Look **2.0.0** are tested. Update main mod and compatibility jar
together. Ordinary world generation, map margins and prior menu fixes remain.

This build does not claim complete PS4 runtime parity: Java supplies entity
physics/AI and ignores some console-only attributes; not every conditional
hint/screenshot token is implemented. Full branch-by-branch tutorial playthrough,
physical Retina/controller hardware and authenticated multiplayer are unverified.
The source contains native addresses, hashes, conversion tools and test records.
