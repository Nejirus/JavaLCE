# Legacy Console 1.17.1 — 2.3.9

* Square now advances all three PS4 crafting information tutorial steps;
  keyboard X does the same. Input is retained through the minimum message time.
* Tutorial controller glyphs use the PS4 45-pixel source size. Line spacing
  and wrapping accommodate the artwork under Minecraft 1.17.1.
* Inventory Take, Quick Move and What's This require a hovered item. Split
  requires a stack of two or more. Carried stacks use placement/swap prompts.
* Removed the competing map-edge cursor correction. PS4 and Java both use
  the 63-pixel edge threshold. North remains decreasing Z.
* Lit campfires offer L2 Use with a shovel when the interaction can extinguish
  them, including soul campfires.

Use Minecraft 1.17.1, Forge 37.1.1 and Java 17. Update both mod jars to 2.3.9.
LCE Look remains 2.0.0. See PS4-INTERACTIONS-239.md for provenance and validation.
