# Legacy Console 1.17.1 — 2.3.10

* Furnace tutorial completion now reports the final glass task, allowing the
  lesson to advance instead of repeating the place/open-furnace instruction.
* The starting area uses PS4's horizontal-only movement restriction. Its
  incorrect height ceiling is removed, and edge correction preserves vertical
  motion.
* Saved tutorial worlds resume through the normal Load Game route without
  the repeated experimental-generator warning, including renamed saves.
* Superflat is hidden in World Options while Legacy is selected.
* The Legacy type button now reads `Legacy`.

Use Minecraft 1.17.1, Forge 37.1.1 and Java 17. Update both mod jars to 2.3.10.
LCE Look remains 2.0.0. Source and validation: PS4-TUTORIAL-FIXES-2310.md.
