# Legacy Console 1.17.1 — 2.3.8

* Square (keyboard X) now cycles the PS4 crafting panel through Inventory,
  Description, Ingredients, then Inventory again. Ingredient names, quantities
  and missing-item marks follow the selected recipe.
* Added original PS4 item-description bindings, including crafted tools and
  original food/armor icons. Newer item text can use the existing Legacy4J fallback.
* Tutorial controller symbols use the mod's existing selected glyph artwork:
  PS4, PS3, Xbox 360, Xbox One, or Automatic detection.
* Inventory hover descriptions are removed. R2 — What's This? (Page Down)
  opens the original upper-right description popup, including with Hints Off.

Use Minecraft 1.17.1, Forge 37.1.1 and Java 17. Update both mod jars to 2.3.8.
LCE Look remains 2.0.0. World generation, tutorial save and prior map/UI fixes
are retained. Physical controller/Retina hardware is not part of the client
fixture coverage. The 2.3.7 tutorial parity limits remain documented.
